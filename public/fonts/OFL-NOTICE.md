# Font licences

Both families are self-hosted rather than requested from a third party, so the judged
path makes no outbound network requests at all.

- **STIX Two Text** — Copyright the STIX Fonts project authors
  (https://github.com/stipub/stixfonts). Licensed under the SIL Open Font
  License, Version 1.1. Chosen because it is drawn for scientific setting
  alongside mathematics, so it shares a register with the Computer Modern
  faces KaTeX renders. It replaced Archivo, which is a grotesk and clashed
  with them.
- **Fira Code** — Copyright the Fira Code Project Authors (https://github.com/tonsky/FiraCode).
  Licensed under the SIL Open Font License, Version 1.1.

The SIL OFL permits redistribution and hosting of the font files, including bundled with
this software, provided they are not sold on their own and this notice is retained.
Full licence: https://openfontlicense.org

Each file is the variable-weight `latin` subset served by Google Fonts; one file covers
every weight this project uses.
