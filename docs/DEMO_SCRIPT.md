# Public demo script

**Target length:** 2:50

**Format:** Screen recording with one narrator. Use no music. Use jump cuts and preloaded browser states.

**Capture rule:** Show the live product first. Keep the pointer still unless it explains an action.

## 0:00–0:14 — Show the product working

**Screen**

Open the learning studio beside the agent. Show only the first two calls:

1. `get_learning_workspace`
2. `check_current_attempt` with `36`

The page changes to the exact missing-path diagnosis.

**Audio**

> A student enters 36. Mathos does not say only “wrong.” The agent reads the live workspace, checks the attempt, and finds the exact route that the student missed.

## 0:14–0:28 — State the thesis

**Screen**

Jump to the landing hero. Show the calculus-to-transformer path and the company proof line.

**Audio**

> This is Mathos, backed by Y Combinator, featured in Forbes, and built for 5M+ learners. We turn one useful mistake into a route from calculus to a transformer the learner trains.

## 0:28–0:57 — Show WebMCP collaboration

**Screen**

Return to the diagnosis left by call two. Keep the agent and the session activity visible. Show only the next call:

3. `show_targeted_lesson`

This call opens the targeted lesson on the page. Its activity entry appears beside the lesson.

**Audio**

> WebMCP makes the page an exact learning surface for people and agents. The agent sees the problem, revision, and safe next actions. Its tool call changes the same page that the learner sees. Both use one state engine, so there is no hidden agent copy of the session.

## 0:57–1:23 — Show real Mathos video

**Screen**

Show the computation graph, then the Mathos video player. Play three to five seconds. Show the 5–10 second first-frame label and the ready full lesson. Do not wait for a new generation.

**Audio**

> The answer 36 means that one derivative path is missing. Mathos opens a real Mathos-generated lesson for this exact mistake. The product can show its first frame in 5–10 seconds, then upgrade to the full video.

## 1:23–1:52 — Prove transfer

**Screen**

Use a jump cut to the next WebMCP calls:

4. `start_transfer_problem`
5. `check_current_attempt` with `8`
6. `get_learning_receipt`

The fifth registered tool appears on call six because `check_current_attempt` serves both problems. End on the visible evidence receipt.

**Audio**

> The agent starts a fresh problem. The learner answers 8. Mathos issues a narrow receipt: the learner found both routes on a new problem in this session. This is evidence, not a fake mastery badge.

## 1:52–2:15 — Reveal the full pathway

**Screen**

Select **Continue the path**. Move from the derivative-path diagram to the ten-stage pathway and the attention equation. Select **Train the tiny transformer**.

**Audio**

> The same habit now travels forward: trace influence, combine routes, and use error to update a system. The pathway connects calculus, vectors, computation graphs, backpropagation, tokens, attention, and transformer blocks.

## 2:15–2:42 — Show real model evidence

**Screen**

Jump to a preloaded 100-step state from the current recording session. Show the parameter count, loss chart, before-and-after raw samples, and one attention head.

**Audio**

> This final model is real. TensorFlow.js trains 6,578 parameters in the browser. These points are measured loss. These characters come directly from the logits. This heatmap is an actual causal attention head, with future characters blocked.

## 2:42–2:50 — End on the company advantage

**Screen**

Return to the hero or hold on the trained evidence frame. End with the Mathos wordmark and deployed URL.

**Audio**

> Mathos owns the math-learning surface and video engine. WebMCP turns that advantage into frontier learning for every learner and agent.

## Recording notes

- Record the WebMCP segment in the ChatGPT in-app browser or Chrome 149+ with WebMCP enabled.
- Show all six calls without hiding the repeated `check_current_attempt` call.
- Show calls one and two only in the opening. Show call three only when the lesson opens.
- Do not reset the session during the recording.
- Preload the video lesson, receipt, pathway, and trained-model states in separate tabs.
- Use jump cuts between those states. Do not show network or training waits.
- Keep the final video between 2:40 and 2:55.
- Export with clear narration and no copyrighted music.
